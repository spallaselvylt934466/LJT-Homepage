# Junteng Liu — Personal Homepage

This is the personal academic homepage of [Junteng Liu](https://github.com/Vicent0205), built from the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template and hosted on GitHub Pages.

The site includes:

- **About / Home** — personal details, education, research interests, skills, research experience, publications, awards, and contact information.
- **Publications** — a full list of publications with individual pages.

## Site configuration

- Site-wide configuration lives in `_config.yml` (author info, navigation, social links).
- Publication entries are Markdown files in `_publications/`.
- The top navigation is defined in `_data/navigation.yml`.

## Running locally

```bash
bundle install
bundle exec jekyll serve -l -H localhost
```

The site will be served from `http://localhost:4000`.
